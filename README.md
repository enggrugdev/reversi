# Othello — Boardroom

An Othello (Reversi) game built with Vue 3 and Vite. Play locally with two
players or choose **Solo vs. AI** to play as Black against the computer as
White. AI difficulty ranges from Easy (random legal moves) through Medium
(positional strategy) to Hard (look-ahead search). Legal moves are highlighted,
scores update as discs are flipped, and the game automatically passes a turn
when a player has no legal moves. In solo mode, **Undo move** takes back your
move and the AI's response together. Use **New game** to start over.

## Setup

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```
